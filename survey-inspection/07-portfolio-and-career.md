# 作品集与职业路线

## 1. 不要只展示“我会飞”

企业真正关心的是你能不能把任务做完。

作品集应该展示：

**需求 → 规划 → 飞行 → 数据 → 处理 → 分析 → 报告 → 复盘。**

---

# 2. 推荐作品集结构

## 项目A：小区域正射测绘

展示：

- 任务说明
- 航线截图
- 原始照片示例
- 正射影像
- QGIS地图
- 测量结果
- 质量检查

## 项目B：建筑/屋顶巡检

展示：

- 巡检区域
- 总览影像
- 缺陷照片
- 缺陷点位图
- 缺陷统计
- 报告

## 项目C：综合项目

同时展示测绘和巡检。

---

# 3. 面试时要能回答的问题

### 飞行

- 为什么这样规划航线？
- 为什么不能只看无人机屏幕？
- 遇到大风怎么办？
- 返航高度怎么确定？

### 航测

- 什么是前向/旁向重叠？
- 什么是GSD？
- 为什么照片会重建失败？
- DSM和DTM有什么区别？
- RTK/PPK/GCP分别解决什么问题？

### GIS

- CRS是什么？
- 为什么同一份数据叠不到一起？
- GeoTIFF和SHP有什么区别？
- 如何从正射影像量面积？

### 巡检

- 一张照片为什么不能直接判断结构安全？
- 如何保证缺陷可以被复核？
- 为什么要拍总览、中景、近景？
- 怎么组织几百张巡检照片？

---

# 4. 进阶职业方向

完成基础能力后可以选择：

### 航测飞手

偏飞行、任务执行和影像采集。

### 航测数据处理

偏摄影测量、点云、GIS和成果制作。

### 无人机巡检

偏现场作业、缺陷记录和报告。

### 测绘数据工程

偏GIS、三维、点云、数据库和自动化。

### 复合型无人机工程师

飞行 + 航测 + GIS + 巡检 + 数据自动化。

---

# 5. 后续再学编程

你之前想学无人机编队编程，不代表这条路浪费了。

当你已经懂：

- 航线
- 坐标
- 影像
- GIS
- 点云
- 任务数据

再学 Python，会比完全不了解无人机业务时更容易理解“代码到底在解决什么问题”。

后续可以把编程用于：

- 批量重命名照片
- 自动整理项目目录
- EXIF/GNSS信息提取
- CSV/Excel数据处理
- GIS批处理
- 巡检缺陷统计
- 自动生成项目报告
- 影像筛选和质量检查

也就是说：**现在不是放弃技术，而是先把技术建立在真实业务上。**

---

# 6. 你的第一份作品集最低标准

完成以下两个项目即可开始展示：

- [ ] 一个完整小型测绘项目
- [ ] 一个完整建筑/屋顶巡检项目
- [ ] 每个项目都有原始数据
- [ ] 每个项目都有处理成果
- [ ] 每个项目都有GIS结果
- [ ] 每个项目都有PDF报告
- [ ] 每个项目都有问题复盘

# 7. 进阶路线

**零基础飞手 → 航测采集 → 摄影测量 → QGIS → 巡检 → RTK/PPK/GCP → LiDAR/热红外 → 点云/GIS工程化 → Python自动化。**

这是比“只学编队代码”更贴近实际无人机作业的一条路线，也保留了你以后重新进入无人机软件/算法开发的入口。
