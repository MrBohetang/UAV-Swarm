# 飞行与作业安全检查清单

> 这是训练用清单，不替代当地法规、制造商手册、项目SOP或现场安全负责人要求。

## A. 飞行前

- [ ] 已确认当地空域、飞行限制、许可/申报等要求
- [ ] 已确认任务区域不存在未经评估的人员风险
- [ ] 已查看天气、风、降雨和能见度
- [ ] 起降区域安全
- [ ] 飞机外观正常
- [ ] 桨叶正常
- [ ] 电机/机臂无明显异常
- [ ] 电池电量与健康状态满足任务
- [ ] 遥控器电量足够
- [ ] 存储卡空间足够
- [ ] 相机/云台正常
- [ ] GNSS/定位状态正常
- [ ] 返航点确认
- [ ] 返航高度经过风险评估
- [ ] 任务航线检查完成
- [ ] 已设置安全边界
- [ ] 已规划紧急降落点
- [ ] 已确认附近无明显电线、塔架、树木等风险
- [ ] 已明确谁负责飞行、谁负责观察环境

## B. 起飞后

- [ ] 起飞后确认姿态和定位正常
- [ ] 检查遥控链路
- [ ] 检查影像是否正常
- [ ] 检查云台是否正常
- [ ] 检查飞机是否按预期响应
- [ ] 发现异常立即中止任务，不为了完成任务冒险

## C. 航测采集

- [ ] 飞行速度适合当前光照和快门
- [ ] 影像清晰
- [ ] 曝光基本稳定
- [ ] 航线覆盖完整
- [ ] 前向/旁向重叠满足项目设计
- [ ] 没有明显漏拍
- [ ] 没有不必要的大幅度姿态变化

## D. 降落后

- [ ] 飞机状态检查
- [ ] 电池检查
- [ ] 相机/云台检查
- [ ] 立即查看照片质量
- [ ] 备份原始数据
- [ ] 保存飞行日志
- [ ] 记录天气和异常

## E. 数据安全

- [ ] 原始数据只读备份
- [ ] 处理数据与原始数据分开
- [ ] 重要成果至少保留两份
- [ ] 项目文件命名统一
- [ ] 记录软件版本
- [ ] 记录处理参数

## F. 巡检安全

- [ ] 不为了拍清楚缺陷而盲目靠近障碍物
- [ ] 不把单张照片当成专业鉴定结论
- [ ] 缺陷必须能回到资产/构件位置
- [ ] 重要缺陷尽量有总览+中景+近景证据
- [ ] 对无法确认的情况标记“待复核”

## G. 什么时候应该直接中止任务

出现以下情况之一时，优先安全而不是成果：

- 天气快速恶化
- 风况超过设备或项目安全边界
- GNSS/定位/链路出现无法解释的异常
- 电池异常
- 周围人员进入危险区域
- 发现未评估障碍物
- 飞机状态异常
- 现场管理人员要求停止

# 训练阶段的底线

**不要用正式项目去学习第一次飞行。**

先在低风险训练环境完成操控和航测练习，再进入有价值资产、复杂环境和专业巡检场景。
